# Agent Skills Spec Notes

- **Required Frontmatter:** The `SKILL.md` file must contain `name` and `description` fields in its YAML frontmatter.
- **Naming Rules:** The `name` field can only contain lowercase letters, numbers, and hyphens. It cannot start or end with a hyphen, nor have consecutive hyphens (`--`).
- **Length Limits:** The `name` field is limited to 64 characters, while the `description` field can be up to 1024 characters long.
- **File Layout:** The `name` field should ideally match the parent directory name where the `SKILL.md` is located. It is also recommended to use the gerund form for the name (e.g., `analyzing-data`).
